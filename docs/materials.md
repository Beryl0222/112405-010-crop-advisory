# 资料口径

作物、田块和农户分别标识，邻田经验不是本田证据。病害与标签规则为合成演练，不提供真实农药或诊疗建议。已执行状态不表示当时判断正确。

`data/case.json`为UTF-8合成原始资料。`records`中的`id`稳定，`kind`或`source`为资料种类，`text`保留原句。其他集合为对象登记或既有业务记录，`sources`与`source`在相应集合中引用原文；`context`补充已发生记录。资料陈述可以冲突、未确认或被更正，不用上传顺序推定效力。新增同类资料使用独立编号，不用原编号表示固定结论。

`data/reference.json`为合成参考表：作物（含编号别名与生育期顺序）、病害症状码、药剂标签适用作物、症状关键词、传闻标记与生育期别名。参考表同样为虚构资料，解析器只按其中关键词做结构抽取，不替经办人员作事实判断。
